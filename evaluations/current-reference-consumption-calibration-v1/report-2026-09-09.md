## 11. Defects discovered

One consumer defect was found: the large-ticket value existed as first-class governed knowledge, but the shared assessment-cardinality helper accepted only 0.13% or 0.14% as the applicable ABVF reference. A correctly scoped 0.15% line therefore could not be recognized as reconciling to its applicable ABVF reference. The code also lacked one unified downstream, claim-constrained reference consumer.

## 12. Implementation changes

- The cardinality helper now accepts the already-adjudicated 0.15% scoped ABVF result as an applicable reference.
- A bounded downstream consumer composes existing current-reference resolution, Mastercard scope selection, statement-local cardinality, Base II candidate provenance, comparison blocking, and rendering permissions.
- Synthetic fixtures, tests, and a repeatable evaluation runner were added.

No catalog entry, rate, industry rule, evidence claim, research behavior, or reusable knowledge authority was added or changed.
